# Poker Dashboard — Simple GitHub Pages Version

This version needs **no npm, no terminal, and no build step**.

## How to upload

1. Extract this ZIP file.
2. Open your GitHub repository.
3. Click **Add file → Upload files**.
4. Drag these files into GitHub:
   - `index.html`
   - `style.css`
   - `script.js`
   - `data.js`
5. Click **Commit changes**.
6. Go to **Settings → Pages**.
7. Select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
8. Save.

Your website should appear after 1–3 minutes.
